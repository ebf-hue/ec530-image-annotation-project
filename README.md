# ec530-image-annotation-project
Event-driven image annotation project using AI and vector databases.

### System Components ###
- Defined events
- Messaging & bus broker
- Document DB
- Vector DB (Embedding Service)
- Annotation service
- Inference service
- Upload service
- CLI

- Vector Index
